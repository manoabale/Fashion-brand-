# Fashion-brand 🧵

A modern fashion e‑commerce front‑end built with **React** and styled with **CSS**, inspired by premium clothing brand layouts.  
This project demonstrates a clean, responsive design with product listings, banners, trust badges, and a professional footer.

---

## ✨ Features
- **Responsive Navigation Bar** with logo, menu links, and cart icon
- **Hero Banner** with background image, overlay text, and call‑to‑action buttons
- **Product Grid** showcasing items with images, prices, and "Add to Cart" buttons
- **Promo Banner** highlighting seasonal sales
- **Footer Sections**:
  - Top footer: trust badges + newsletter signup
  - Bottom footer: social media icons + payment method logos
